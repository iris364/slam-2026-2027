## Quizz réponsees : 

1. return : 
return arrête l’exécution de la fonction à cet endroit et peut renvoyer une valeur à l’appelant.

2. $demande :
$demande est la variable qui reçoit l’élément courant du tableau $demandes à chaque tour de boucle.

3. == / === :
== compare les valeurs avec conversion éventuelle de type ; === compare la valeur et le type sans conversion implicite.

4. Git : 
git status -> git add . -> git commit -m "..." -> git push.
